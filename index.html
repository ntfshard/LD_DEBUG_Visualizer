Generating Dynamic Linker Logs

To generate comprehensive logs compatible with this tool, run your target application with the following command on Linux:

LD_DEBUG=all,unused,statistics LD_DEBUG_OUTPUT=~/my_stats_log ./my_application
Environment Variables Explained:
  • LD_DEBUG=all: Traces symbol resolution, bindings, file lookups, link maps, and scopes.
  • unused: Flags any loaded libraries (DSOs) whose symbols were never actually referenced.
  • statistics: Outputs dynamic linker cycle counts and relocation timing breakdown.
  • LD_DEBUG_OUTPUT=...: Redirects diagnostics to <path>.<PID> instead of mixing with stderr.
